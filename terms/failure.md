# Отказ

Система в целом перестала предоставлять требуемый сервис конечному пользователю
— сбои не удалось удержать внутри.

## Определение

Отказ — ситуация, когда вся система прекращает предоставление требуемого сервиса
конечному пользователю. Это глобальное явление на уровне системы: результат
того, что сбои не удалось обработать.

Цепочка: [сбой](fault.md) (в компоненте) → обработка (отказоустойчивость) →
отказ, если обработка не удалась.

Примеры:

- веб-приложение недоступно всем пользователям;
- полная остановка обработки транзакций;
- потеря возможности доступа к данным.

Сбои неизбежны. Проектируем предотвращение, восстановление и недопущение
перехода [сбоев](fault.md) в отказ.

Scope: `architecture`.

## Синонимы

- Failure

## Запрещённые смешения

- Не [сбой](fault.md) компонента. Выход из строя одного узла кластера при живом
  сервисе для пользователя — сбой, не отказ.

## Чем не является

- Не деградация, которую пользователь ещё получает как сервис (это может быть
  следствие сбоя).
- Не [технический долг](technical-debt.md).
