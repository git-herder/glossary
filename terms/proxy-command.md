# Прокси-команда

**Прокси-команда** (proxy command) отбирает рабочие копии и на каждой
запускает одноимённую команду git, передавая ей хвост аргументов без разбора.

## Определение

Прокси-команда не подменяет семантику git своей логикой. На запуске она
собирает рабочие копии, для каждой запускает одну и ту же команду git и
отчитывается по коду возврата этой копии.

Аргументы запуска делятся на префикс и хвост. В префиксе только флаги самого
Git Herder: общие флаги запуска и флаги отбора рабочих копий. Они могут стоять
до имени команды и сразу после него. Первый токен, который не является таким
флагом, начинает хвост. Разделитель `--` заканчивает префикс и в хвост не
входит. Хвост копируется в git пословно и одинаков для каждой копии.

Подкоманда git входит в хвост и отдельной командой Git Herder не становится.
У команды `remote` слова `add` и `set-url` начинают хвост.

Scope: `product`.

## Синонимы

- proxy command (EN)

## Запрещённые смешения

- Не команда git. Прокси-команда запускает её на отобранных копиях.
- Не [ремот](remote.md). Ремот — удалённый репозиторий рабочей копии. Имя
  команды `remote` называет команду `git remote`, а не ремот.
- Не [поток выполнения команды](command-flow.md). Поток — шаги алгоритма любой
  команды. Прокси-команда — класс команд, у которых хвост аргументов уходит
  в git.

## Чем не является

- Не команда, которая разбирает флаги git и сама собирает из них вызов.
- Не отдельная подкоманда Git Herder на каждую подкоманду git.
