# SCM-платформа

Платформа для хранения исходного кода и совместной разработки программного
обеспечения, поддерживающая полный цикл — от планирования работы до развёртывания
и эксплуатации.

## Определение

**SCM-платформа** (Source Code Management) — это сервис или программный продукт,
который размещает репозитории исходного кода и даёт командам инструменты
совместной разработки. Типичные представители: GitLab, GitHub, GitVerse,
Bitbucket.

Помимо версионирования кода, такая платформа обычно покрывает смежные этапы
жизненного цикла ПО: планирование и учёт работ, code review, CI/CD, управление
релизами и артефактами, иногда — эксплуатацию и наблюдаемость. Конкретный набор
возможностей зависит от продукта и конфигурации организации.

Scope: `product`.

## Синонимы

- VCS-хостинг (Version Control System hosting) — допустимо, если из контекста
  ясно, что речь о платформе целиком, а не только о приёме push в удалённый
  репозиторий.

## Запрещённые смешения

- Не путать с локальным Git или другим VCS-клиентом: SCM-платформа — удалённый
  сервис и экосистема вокруг него.
- Не путать с одним git-репозиторием: репозиторий — единица хранения; платформа
  — хост и набор сервисов над многими репозиториями.
- Не сводить термин только к CI/CD или только к issue-трекеру: это части
  возможного набора, но не синонимы SCM-платформы.

## Чем не является

- Не self-hosted runner или отдельный registry артефактов без контекста платформы.
- Не [замысел продукта](product-intent.md), не [Capability](capability.md) и не
  прикладной код в `application/`.

## Примеры

- GitLab (SaaS или self-managed)
- GitHub
- GitVerse
- Bitbucket
