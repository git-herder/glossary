# Function

Часть коллектива с общей специализацией; без оперативного планирования, в
отличие от юнита.

## Определение

Функция — часть коллектива, объединённая по принципу идентичности специализации
и профессиональных знаний и навыков сотрудников. Совместного у членов функции —
специализация, бизнес-процессы и инструментарий. В отличие от юнита, функция
**не** осуществляет оперативного планирования.

Scope: `process`.

## Синонимы

- Функция
- Function (орг.)

## Запрещённые смешения

- Не путать с [Capability](capability.md) / «функцией продукта»: Capability —
  способность продукта, Function — организационная единица.
- Не роль: лидер функции — роль FL, сама Function — организационная единица.

## Чем не является

- Не [Unit](unit.md): у юнита есть совместное оперативное планирование.
- Не [Stream](stream.md): стрим — рамка поставки, функция входит в стрим.
