# Поток выполнения команды

**Поток выполнения команды** (command flow, execution flow) — последовательность шагов алгоритма одной CLI-команды Git Herder.

## Определение

У каждой команды (`clone`, `report`, `profile`, …) свой поток выполнения. Команды **не знают** о потоках других команд.

Платформенные механизмы (логирование, конфиг, ретрай и т.д.) вызываются **изнутри** потока команды, но сами по себе не являются шагами потока и не образуют общего процесса между командами.

Scope: `architecture`

## Синонимы

- command flow (EN)
- execution flow (EN)

## Запрещённые смешения

- Не использовать слово «pipeline» без уточнения — только «поток выполнения команды».

## Чем не является

- Не сквозной платформенный механизм — логирование, ретрай и подобные используются в потоке, но не являются его шагами по смыслу домена.
